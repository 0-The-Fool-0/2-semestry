# Учебные работы второго семестра — C++, MASM и Qt

[English version](README.md)

Коллекция университетских лабораторных работ второго семестра специальности «Прикладная информатика». Лабораторные и разные реализации сохранены отдельно: репозиторий не является одним общим приложением.

## Что представлено

| Направление | Материалы репозитория |
|---|---|
| **Программирование на C++ и структуры данных** | Шаблоны классов, массивы и структуры, обработка текстовых файлов, регулярные выражения, двусвязные списки и работа с записями. |
| **Ассемблер / машинно-ориентированное программирование** | Исходники MASM и программы на C++, связанные с заданиями по ассемблеру. |
| **Разработка приложений на Qt** | Небольшие Qt-проекты, включая работу со списками и интерфейс для обработки записей о лекарствах. |
| **Файлы и представление данных** | Примеры входных текстовых файлов, учебные записи студентов и файлы для лабораторных. Их важно отличать от артефактов, которые создаются локальной сборкой. |
| **Visual Studio / Qt Creator** | Оригинальные файлы проектов (`.vcxproj`, `.filters`, `.pro`) сохранены, чтобы открывать отдельные задания в соответствующей IDE. |

## Структура репозитория

- `2 сем лаб №2 С++ Классы-шаблоны/` — работа с шаблонами классов, примеры ввода массивов/структур и учебные записи студентов.
- `Лаба №3 С++ Регулярные/` — задание по регулярным выражениям с примерами входных и выходных данных.
- `Лаба №4 2 сем С++ Реализация двухсвязного списка/` — лабораторная по двусвязному списку и связанные исходники/заголовки.
- `Lab5_2sem_QT_list/` — Qt-проект для работы со списками.
- `untitled9/` — Qt Widgets-приложение для записей о лекарствах с шаблонным заголовочным файлом и UI-формой.
- `asm/`, `assembler/`, `Кр асм2/`, `лаба ассемблер/`, `лаба ассемблер массивы/` — отдельные задания по ассемблеру и совместной работе C++/ассемблера.

Названия каталогов намеренно оставлены близкими к исходным названиям лабораторных, чтобы их можно было сопоставлять с заданиями.

## Сборка и запуск

Единой сборки для всей коллекции нет. Открывайте соответствующий файл `.sln`, `.vcxproj` или `.pro` в совместимой Visual Studio либо Qt Creator и собирайте конкретное задание отдельно.

- Для проектов C++ может потребоваться компилятор MSVC.
- Для ассемблерных проектов могут потребоваться инструменты MASM, настроенные для Visual Studio.
- Для Qt-проектов нужны совместимый Qt kit и qmake.
- Несколько лабораторных читают файлы относительно рабочей директории процесса. Если настройки проекта не указывают иначе, запускайте их из каталога конкретной лабораторной.

Не утверждается, что все работы собираются на любой платформе. Часть заданий может быть незавершённой или сохранять особенности старой реализации.

## Очистка

Из текущей версии удалены закоммиченные результаты сборки, журналы диагностики компилятора, пользовательские настройки IDE и промежуточные сгенерированные файлы. Исходники, описания проектов и учебные входные данные сохранены. Корневой `.gitignore` помогает не добавлять подобный локальный мусор повторно.

## Учебный контекст

Материалы связаны с программной частью учебной программы второго курса: **алгоритмы и структуры данных**, **машинно-ориентированное программирование**, **программирование компьютерной графики**, **промышленное программирование** и **методы вычислений**. Это архив отдельных исходников, а не утверждение, что в репозитории полностью реализованы все перечисленные дисциплины.
